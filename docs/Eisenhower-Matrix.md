# Eisenhower Matrix

## Do — Important and Urgent (MVP)

- Manage projects, team members, and roles
- Create, assign, update, and delete tasks
- Track deadlines, priorities, statuses, effort, and dependencies
- Submit progress updates and report blockers
- Display progress, overdue work, blockers, and workloads
- Detect basic project risks with Java rules
- Generate AI summaries and recommended next actions
- Require manager approval for AI recommendations

## Schedule — Important but Not Urgent (Version 2.0+)

- Generate meeting agendas
- Extract action items from meeting notes
- Send deadline and blocker notifications
- Recommend workload rebalancing
- Display project-health trends
- Export reports and connect external calendars

## Delegate — Urgent but Not Important (Use a Library)

- Use JavaFX for interface components
- Use Jackson for JSON processing
- Use Java `HttpClient` for AI API requests
- Use JUnit and Mockito for automated testing
- Use Maven for builds and dependency management

## Delete — Not Important and Not Urgent

- Real-time team chat and video calls
- Automatic AI task reassignment without approval
- AI scoring or ranking of team members
- Voice recording and transcription
- Separate native mobile applications
- Social profiles, public feeds, and achievement badges
